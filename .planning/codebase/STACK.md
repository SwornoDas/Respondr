# Technology Stack

## Core Frameworks
- **Next.js 16.2.4**: React framework with App Router support.
- **React 19.2.4**: UI library for building components.
- **TypeScript 5**: Static typing for JavaScript.

## Styling & UI
- **Tailwind CSS 4**: Utility-first CSS framework for styling.
- **Lucide React**: Icon library for UI elements.

## Real-time & Communication
- **Socket.io-client**: Client-side library for real-time bidirectional communication.
- **Twilio**: (Planned/Partial) Voice and SMS escalation service.

## Backend & Database
- **Supabase**: (Planned/Partial) Backend-as-a-Service for database and authentication. `supabase/schema.sql` is present.
- **Next.js API Routes**: Serverless functions for handling API requests.

## Deployment
- **Vercel**: Deployment platform for Next.js applications.
